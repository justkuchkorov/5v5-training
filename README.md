# 5v5 Training Library

An interactive 3D football training site: 47 drills shown as animated demos on a 40 m × 20 m futsal pitch, a 75-minute session timer and a 4-week plan checklist.

Everything is in `index.html` (Three.js is loaded from a CDN). Open it in a browser, or host it as a static site.

To add a drill, edit the `DRILLS` list at the top of `index.html`; the comment above it explains the format.
